# 💬 ChatSphere — Anonymous Global Chat

A free, real-time, anonymous chat website. No registration. No tracking. Just talk.

## Features
- 🌍 Multiple themed rooms (Global, Chill, Gaming, Music, Tech, Random)
- 👻 Truly anonymous (random usernames per session)
- ⚡ Real-time messages via Firebase
- 👥 Live online user count
- ⌨️ Typing indicators
- 🌙 Dark/Light mode
- 📱 Mobile responsive
- 🚫 Rate limiting & XSS protection
